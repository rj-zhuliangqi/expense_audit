# 费用稽核风险等级配置

`aiAuditSummaryFinance` 是给财务看的核销单级统计，格式为：

```text
本单高风险 N 项、中低风险 N 项，阻断 N 项，已通过 N 项稽核项。
```

各费用类型分别维护自己的配置文件：

- 通讯费：`expense_audit_orchestrator/profiles/telecom/audit_risk_levels.json`
- 业务招待费：`expense_audit_orchestrator/profiles/entertainment/audit_risk_levels.json`
- 个人交通费：`expense_audit_orchestrator/profiles/personal_transport/audit_risk_levels.json`

配置文件的 `rules` 使用稽核编码作为键，`riskLevel` 支持：

- `high`：高风险
- `medium_low`：中低风险
- `blocking`：阻断

所有 `E` 开头的编码在代码中强制按阻断统计，即使 JSON 误配为其他等级也不会改变结果。`W` 开头的编码按对应 profile 的 JSON 配置统计；新 `W` 编码如果暂时没有配置，会按高风险保守统计，避免漏计。`SYS-*` 等非 `E/W` 编码只有显式配置为 `blocking` 时才建议纳入固定口径；当前正式配置均已列为阻断。

风险配置由 profile 首次加载时读入并缓存到进程内存，不会针对每张核销单重复读取磁盘。修改 JSON 后需要重启 worker/服务，才能让新配置生效。

当前新增费用类型的配置口径：

| Profile | W 编码 | 当前等级 | 依据 |
|---|---|---|---|
| `telecom` | `W28` | 中低风险 | 个人抬头预警，流程图为 WARNING |
| `telecom` | `W32` | 高风险 | 备案手机号不一致，流程图为 REJECT |
| `telecom` | `W40` | 中低风险 | 账单周期与报销提交年度不一致，原编码为 E32 |
| `entertainment` | `W33` | 中低风险 | 礼品数量检查，代码标注为弱控 WARNING |
| `entertainment` | `W34` | 高风险 | 发票号码连续/近似，存在发票连号风险 |
| `entertainment` | `W31` | 高风险 | 虚开发票高风险预警，转财务重点复核 |

如果财务后续调整某个 `W` 稽核点的风险等级，只需修改对应 profile 的 JSON 配置并重启服务，不需要修改汇总代码。
