# 核销任务 Token 与服务器预算

## 1. 单核销单、单发票 Token 费用

Token 按前面确定的最大预算值计算，已经包含字段冗余和轻微试错空间。价格单位为美元/百万 Token，人民币按 `1 美元 = 7.2 元` 估算。

| 费用类型 | 最大预算输入 Token | 最大预算输出 Token | 未命中缓存费用 |
|---|---:|---:|---:|
| 通讯费 `telecom` | 9,300 | 460 | **约 ¥0.030/单**  |
| 个人交通费 `personal_transport` | 4,800 | 320 | **约 ¥0.016/单** |
| 业务招待费高风险路径 `entertainment` | 5,600 | 360 | **约 ¥0.019/单**  |

计算价格：输入未命中缓存 `$0.41095/1M`，输出 `$0.8219/1M`，输入命中缓存 `$0.003424/1M`。公式为：`(输入 Token × 输入单价 + 输出 Token × 输出单价) / 1,000,000 × 7.2`。
