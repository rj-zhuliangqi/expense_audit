# 个人交通费稽核风险等级配置

配置文件：`expense_audit_orchestrator/profiles/personal_transport/audit_risk_levels.json`。

程序在个人交通费 profile 首次加载时读取该 JSON，并在当前进程内缓存；不会针对每张核销单重复读文件。

## 配置规则

- `E` 开头的稽核编码无论配置内容如何，代码都会按**阻断**处理。
- `W` 开头的稽核编码需要配置 `riskLevel`：
  - `high`：高风险
  - `medium_low`：中低风险
- `blocking`：阻断。非 `E` 编码（例如 `SYS-001`）如需按阻断统计，可显式配置。
- 新增 `W` 稽核点时，必须在配置文件中增加编码和风险等级；当前未配置的 `W` 会按高风险保守统计，避免漏报。

## 汇总口径

`aiAuditSummaryFinance` 统计每个实际输出的稽核结果：

```text
本单高风险 N 项、中低风险 N 项，阻断 N 项，已通过 N 项稽核项。
```

已通过项不再按风险等级拆分；未通过项按照编码对应的风险等级计入高风险、中低风险或阻断。对于核销单级的 `E31`、`W33`，只统计最后一张发票承载的结果，避免重复计数。四类数量之和就是本次实际统计的全部稽核点。
